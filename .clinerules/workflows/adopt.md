# Adopt an existing or cloned repo

Read-only until I say "go". Do not change any code.

1. Read README, config files (package.json, requirements.txt, pyproject.toml and similar), the folder tree and /docs if present. Never open .env files.
2. Read-only git checks: `git status`, `git branch --show-current`, `git remote -v`, `git log --oneline -10`.
3. Report in 15 lines max: what the project does, how it is organised (file map), how to run and test it, what looks reusable, risks and unknowns. Write "not found" instead of guessing.
4. Ask up to 3 questions if anything is unclear.
5. Draft NOTES.md using these headings: What It Does, How It's Organized, Project Scope, Standing Rules, Samples and Docs, Steps, Done Log, Current Step, Next Step, Known Issues, Last Working Version (use the current commit hash from git log). Show me the draft and save it only after I approve.
6. Remind me: if this is someone else's repo, I should fork it or work on my own branch before changing anything.
