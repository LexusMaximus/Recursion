# docs/lumiverse

Verbatim copy of the Lumiverse developer docs. This is the API source of truth.
Do not edit these files. Re-run tools/copy-lumiverse-docs.sh (or .ps1) to refresh.

- ref/        core docs for early steps (manifest, permissions, interceptors, generation,
              decisions, storage, council, commands, examples)
- ref-later/  docs for later steps (events, chat mutation, UI, frontend communication)

ref/, ref-later/ and COPIED.txt are git-ignored. On a fresh clone, run the script again.
See COPIED.txt for the source path and date of the last copy.
